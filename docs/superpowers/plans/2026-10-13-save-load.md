# Run & Build Save/Load Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Players can save named run progress (Escape menu) and builds (death screen / Escape menu), then load them from a searchable home-screen list.

**Architecture:** New `CrystalFlux.Save` assembly holds DTOs, file store, asset catalog, capture/apply logic and UI. Existing assemblies get small hooks: capture/restore methods and a `WaveStarting` event. They never reference Save. Restore replays skill nodes and awakenings (for their side effects), then overwrites stats with the saved clean stats, then re-adds stats from still-active permanent status effects.

**Tech Stack:** Unity 6000.4.6f1, C#, `JsonUtility`, TextMeshPro, uGUI, Unity Test Framework 1.6 (EditMode).

**Spec:** `docs/superpowers/specs/2026-10-13-save-load-design.md`

## Global Constraints

- Never delete any ScriptableObject asset (`.asset`/`.meta`). Editor tooling only writes `Assets/Resources/SaveAssetCatalog.asset`.
- No comments, docstrings or TODO markers in code files.
- Match surrounding style: `namespace CrystalFlux.<X>`, Allman braces, expression-bodied one-liners, `TryGetComponent`, `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)] ResetStatics` for statics.
- Commit per task on branch `feat/save`, conventional messages, stage only touched files (never `git add -A`, never TODO.md).
- Save root: `Application.persistentDataPath/saves/{builds|runs}/<id>.json`; atomic write via tmp + `File.Replace`/`File.Move`.
- Run saves are consumed on load. Builds saved during ironman are `readOnly` (cannot load).
- Incompatible = any referenced catalog id missing, or `formatVersion` > current. Rebalanced assets are fine.
- Default names: run `"{Mode} {Difficulty} - Wave {N}"`, build `"{Basic} / {Skill} - Wave {N}"`. Names trimmed, 1–40 chars.

## Review Focus

- Save Progress pressed while an anomaly/contract/reward/synergy panel is open: button must be non-interactable, never write a half-resolved state. Test: `RunSaveRules_Blocks_WhenPicksPending`.
- Two saves with the same name differing only by case/whitespace: treated as the same name (overwrite prompt). Test: `SaveStore_FindByName_IgnoresCaseAndTrim`.
- Corrupt or empty JSON file in the saves folder: the list must still open and skip it. Test: `SaveStore_List_SkipsCorruptFiles`.
- Load Run when the restore throws: the save must not be lost. Test: `RunLoadTransaction_RestoresFile_OnFailure`.
- Search with extra spaces / mixed case / attack name only: matches like skill tree search. Test: `SaveQuery_Search_MultiTermCaseInsensitive`.

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using UnityEngine;

namespace CrystalFlux.SaveSystem
{
    public static class SaveStore
    {
        public const int MaxNameLength = 40;

        private static string root;

        public static string Root
        {
            get => root ??= Path.Combine(Application.persistentDataPath, "saves");
            set => root = value;
        }

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
        private static void ResetStatics() => root = null;

        public static string DirFor(SaveKind kind) => Path.Combine(Root, kind == SaveKind.Build ? "builds" : "runs");

        private static string PathFor(SaveKind kind, string id) => Path.Combine(DirFor(kind), id + ".json");

        public static string NormalizeName(string name)
        {
            if (string.IsNullOrWhiteSpace(name)) return "";
            name = name.Trim();
            return name.Length > MaxNameLength ? name.Substring(0, MaxNameLength).TrimEnd() : name;
        }

        public static bool SameName(string a, string b)
            => string.Equals(NormalizeName(a), NormalizeName(b), StringComparison.OrdinalIgnoreCase);

        public static List<SaveFile> List(SaveKind kind)
        {
            var result = new List<SaveFile>();
            string dir = DirFor(kind);
            if (!Directory.Exists(dir)) return result;

            foreach (string path in Directory.GetFiles(dir, "*.json"))
            {
                SaveFile f = ReadPath(path);
                if (f != null && f.meta != null && f.meta.kind == kind) result.Add(f);
            }

            return result;
        }

        public static SaveFile Read(SaveKind kind, string id)
        {
            if (string.IsNullOrEmpty(id)) return null;
            string path = PathFor(kind, id);
            return File.Exists(path) ? ReadPath(path) : null;
        }

        private static SaveFile ReadPath(string path)
        {
            try
            {
                string json = File.ReadAllText(path);
                if (string.IsNullOrWhiteSpace(json)) return null;
                SaveFile f = JsonUtility.FromJson<SaveFile>(json);
                if (f == null || f.meta == null || string.IsNullOrEmpty(f.meta.id)) return null;
                f.build ??= new BuildData();
                f.run ??= new RunData();
                return f;
            }
            catch (Exception e)
            {
                Debug.LogWarning($"[SaveStore] Skipping unreadable save '{path}': {e.Message}");
                return null;
            }
        }

        public static bool Write(SaveFile file)
        {
            if (file == null || file.meta == null) return false;
            if (string.IsNullOrEmpty(file.meta.id)) file.meta.id = Guid.NewGuid().ToString("N");
            file.meta.name = NormalizeName(file.meta.name);

            string path = PathFor(file.meta.kind, file.meta.id);
            string tmp = path + ".tmp";

            try
            {
                Directory.CreateDirectory(DirFor(file.meta.kind));
                File.WriteAllText(tmp, JsonUtility.ToJson(file, true));

                if (File.Exists(path)) File.Replace(tmp, path, null);
                else File.Move(tmp, path);
                return true;
            }
            catch (Exception e)
            {
                Debug.LogWarning($"[SaveStore] Save failed: {e.Message}");
                try { if (File.Exists(tmp)) File.Delete(tmp); }
                catch { }
                return false;
            }
        }

        public static bool Delete(SaveKind kind, string id)
        {
            try
            {
                string path = PathFor(kind, id);
                if (!File.Exists(path)) return false;
                File.Delete(path);
                return true;
            }
            catch (Exception e)
            {
                Debug.LogWarning($"[SaveStore] Delete failed: {e.Message}");
                return false;
            }
        }

        public static bool Rename(SaveKind kind, string id, string name)
        {
            string n = NormalizeName(name);
            if (n.Length == 0) return false;

            SaveFile f = Read(kind, id);
            if (f == null) return false;

            f.meta.name = n;
            return Write(f);
        }

        public static SaveFile FindByName(SaveKind kind, string name)
        {
            foreach (SaveFile f in List(kind))
                if (SameName(f.meta.name, name)) return f;
            return null;
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using CrystalFlux.EntitySystem;
using UnityEngine;
using Object = UnityEngine.Object;

namespace CrystalFlux.SaveSystem
{
    public class SaveAssetCatalog : ScriptableObject
    {
        public const string ResourcePath = "SaveAssetCatalog";

        [Serializable]
        public class Entry
        {
            public string id;
            public string name;
            public Object asset;
        }

        public List<Entry> entries = new();

        private Dictionary<string, Entry> byId;
        private Dictionary<Object, string> byRef;

        private static SaveAssetCatalog instance;

        [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
        private static void ResetStatics() => instance = null;

        public static SaveAssetCatalog Instance
        {
            get
            {
                if (instance == null) instance = Resources.Load<SaveAssetCatalog>(ResourcePath);
                return instance;
            }
        }

        public void SetEntries(List<Entry> list)
        {
            entries = list ?? new List<Entry>();
            byId = null;
            byRef = null;
        }

        private void EnsureLookup()
        {
            if (byId != null) return;

            byId = new Dictionary<string, Entry>();
            byRef = new Dictionary<Object, string>();

            foreach (Entry e in entries)
            {
                if (e == null || string.IsNullOrEmpty(e.id) || e.asset == null) continue;
                byId[e.id] = e;
                byRef[e.asset] = e.id;
            }
        }

        public bool Has(string id)
        {
            EnsureLookup();
            return !string.IsNullOrEmpty(id) && byId.ContainsKey(id);
        }

        public T Get<T>(string id) where T : Object
        {
            EnsureLookup();
            return !string.IsNullOrEmpty(id) && byId.TryGetValue(id, out Entry e) ? e.asset as T : null;
        }

        public string GetId(Object asset)
        {
            if (asset == null) return "";
            EnsureLookup();
            if (byRef.TryGetValue(asset, out string id)) return id;

            string wanted = PlayerAttackHandler.NormalizeAttackName(asset.name);
            Type t = asset.GetType();

            foreach (Entry e in entries)
            {
                if (e == null || e.asset == null || e.asset.GetType() != t) continue;
                if (PlayerAttackHandler.NormalizeAttackName(e.name).Equals(wanted, StringComparison.OrdinalIgnoreCase)) return e.id;
            }

            return "";
        }

        public static string CompatibilityIssue(SaveMeta meta, SaveAssetCatalog catalog)
        {
            if (meta == null) return "Unreadable save";
            if (meta.formatVersion > SaveMeta.CurrentFormat) return "Saved by a newer game version";
            if (catalog == null) return "Save catalog missing";

            int missing = 0;
            if (meta.referencedIds != null)
                foreach (string id in meta.referencedIds)
                    if (!string.IsNullOrEmpty(id) && !catalog.Has(id)) missing++;

            return missing == 0 ? null : $"{missing} referenced asset{(missing > 1 ? "s" : "")} missing in this version";
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Text;

namespace CrystalFlux.SaveSystem
{
    public enum SaveSort { Date, Wave, Dps, Name }

    public static class SaveQuery
    {
        private static readonly char[] Separators = { ' ', '\t', ',' };

        public static string[] Terms(string search)
            => string.IsNullOrWhiteSpace(search)
                ? Array.Empty<string>()
                : search.ToLowerInvariant().Split(Separators, StringSplitOptions.RemoveEmptyEntries);

        public static string Haystack(SaveMeta m)
        {
            var sb = new StringBuilder();
            sb.Append(m.name).Append(' ').Append(m.modeName).Append(' ').Append(m.difficultyName);
            if (m.ironman) sb.Append(" ironman");
            if (m.attackNames != null)
                foreach (string a in m.attackNames) sb.Append(' ').Append(a);
            return sb.ToString().ToLowerInvariant();
        }

        public static bool Matches(SaveMeta m, string[] terms)
        {
            if (terms == null || terms.Length == 0) return true;
            string h = Haystack(m);
            foreach (string t in terms)
                if (!h.Contains(t)) return false;
            return true;
        }

        public static List<SaveFile> Apply(List<SaveFile> files, string search, SaveSort sort)
        {
            string[] terms = Terms(search);
            var result = new List<SaveFile>();
            if (files == null) return result;

            foreach (SaveFile f in files)
                if (f?.meta != null && Matches(f.meta, terms)) result.Add(f);

            result.Sort((a, b) => sort switch
            {
                SaveSort.Wave => b.meta.wave.CompareTo(a.meta.wave),
                SaveSort.Dps => b.meta.peakDps.CompareTo(a.meta.peakDps),
                SaveSort.Name => string.Compare(a.meta.name, b.meta.name, StringComparison.OrdinalIgnoreCase),
                _ => string.CompareOrdinal(b.meta.savedAtUtc, a.meta.savedAtUtc)
            });

            return result;
        }
    }
}
```

`savedAtUtc` is written with `DateTime.UtcNow.ToString("o")` (Task 9), so ordinal comparison sorts it chronologically.

```csharp
using System.Collections.Generic;
using CrystalFlux.Core;
using UnityEngine;

namespace CrystalFlux.SaveSystem
{
    public static class StatsMath
    {
        public static bool IsFlag(StatType t) => t switch
        {
            StatType.isImmune or StatType.isAlive or StatType.IsDashing or StatType.IsAttacking
                or StatType.CanMove or StatType.CanDash or StatType.CanAttack or StatType.CanGainHp
                or StatType.CanGainMana or StatType.CanGainStamina or StatType.DashShouldApplyIFrame => true,
            _ => false
        };

        public static string CleanStatsJson(EntityStats live, List<StatBuff> effectStats)
        {
            if (live == null) return "";

            EntityStats copy = Object.Instantiate(live);
            try
            {
                if (effectStats != null)
                    foreach (StatBuff b in effectStats)
                        if (!IsFlag(b.type)) copy.Apply(b.type, -b.value);

                return JsonUtility.ToJson(copy);
            }
            finally
            {
                Object.DestroyImmediate(copy);
            }
        }
    }
}
```

`DestroyImmediate` is used because this runs both in tests and at runtime on a non-scene object. At runtime, `Object.Destroy` is also acceptable if the editor warns.

```csharp
using System.Collections.Generic;

namespace CrystalFlux.SaveSystem
{
    public static class RunSaveRules
    {
        public static bool CanSaveProgress(bool runStarted, bool waveActive, bool idleBetweenWaves, bool hasWaveStartSnapshot, bool playerDead)
        {
            if (playerDead || !runStarted) return false;
            if (idleBetweenWaves) return true;
            return waveActive && hasWaveStartSnapshot;
        }

        public static bool CanSaveBuild(bool runStarted, bool idleBetweenWaves, bool playerDead)
            => playerDead || runStarted && idleBetweenWaves;

        public static string DefaultRunName(string mode, string difficulty, int wave)
            => SaveStore.NormalizeName($"{mode} {difficulty} - Wave {wave}");

        public static string DefaultBuildName(IList<string> attackNames, int wave)
        {
            string head = attackNames == null || attackNames.Count == 0
                ? "Build"
                : attackNames.Count == 1 ? attackNames[0] : $"{attackNames[0]} / {attackNames[1]}";
            return SaveStore.NormalizeName($"{head} - Wave {wave}");
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using CrystalFlux.Core;
using CrystalFlux.EntitySystem;
using CrystalFlux.SkillTree;
using CrystalFlux.StatusEffectSystem;
using CrystalFlux.WaveSystem;
using UnityEngine;

namespace CrystalFlux.SaveSystem
{
    public static class BuildCapture
    {
        public static BuildData Capture(GameObject player, SaveAssetCatalog c, AnomalyInstance contract)
        {
            var b = new BuildData();
            if (player == null || c == null) return b;

            var effectStats = new List<StatBuff>();
            if (player.TryGetComponent<StatusEffectManager>(out var sem)) sem.CollectAppliedStats(effectStats);
            if (player.TryGetComponent<EntityStatManager>(out var esm)) b.statsJson = StatsMath.CleanStatsJson(esm.Stats, effectStats);

            if (player.TryGetComponent<PlayerAttackHandler>(out var pah))
                foreach (AttackData a in pah.attacks)
                    if (a != null) b.attacks.Add(new AttackSlot { type = a.type, id = c.GetId(a) });

            if (player.TryGetComponent<PlayerUpgradeManager>(out var pum))
                foreach (PlayerUpgrade u in pum.activeUpgrades)
                    if (u != null) b.upgradeIds.Add(c.GetId(u));

            if (player.TryGetComponent<PlayerSkillTree>(out var tree))
            {
                b.skillTree.unlockedOrder.AddRange(tree.UnlockOrder);
                b.skillTree.skillPoints = tree.SkillPoints;
                b.skillTree.choseStarting = tree.choseStarting;
            }

            if (player.TryGetComponent<StatSynergyManager>(out var ssm))
            {
                var states = new List<(StatType, StatType, float, float)>();
                ssm.GetState(states);
                foreach (var (source, target, pct, applied) in states)
                    b.synergies.Add(new SynergyState { source = source, target = target, pct = pct, applied = applied });
            }

            if (contract != null && contract.amd != null)
            {
                b.hasContract = true;
                b.contract.anomalyId = c.GetId(contract.amd);
                b.contract.creationState = contract.creationState;
            }

            b.peakDps = DpsMeter.Peak;
            b.playtimeSeconds = RunSession.Playtime;
            return b;
        }

        public static RunData CaptureRun(WaveManager wm, SaveAssetCatalog c)
        {
            var r = new RunData();
            if (wm == null || c == null) return r;

            var dto = new RunStateDto();
            wm.CaptureRunState(dto);

            r.waveManagerKind = wm is UnlimitedWaveManager ? WaveManagerKind.Unlimited : WaveManagerKind.Regular;
            r.sequenceId = c.GetId(dto.sequence);
            r.waveIndex = dto.waveIndex;
            r.difficultyId = c.GetId(wm.difficulty);
            r.modeId = c.GetId(wm.mode);
            r.ironman = IronmanSelector.Enabled;
            r.rerolls = dto.rerolls;
            r.additionalQuality = dto.additionalQuality;
            r.synergyChanceBonus = dto.synergyChanceBonus;
            foreach (var a in dto.availableRare) r.availableRareIds.Add(c.GetId(a));
            foreach (var u in dto.availableTreasure) r.availableTreasureIds.Add(c.GetId(u));
            foreach (var a in dto.availableCorruptionSpecial) r.availableCorruptionSpecialIds.Add(c.GetId(a));
            r.pendingOccasionalRerolls = dto.pendingOccasionalRerolls;
            r.pendingOccasionalSkillPoints = dto.pendingOccasionalSkillPoints;
            r.pendingAnomalyRerolls = dto.pendingAnomalyRerolls;
            r.pendingAnomalySkillPoints = dto.pendingAnomalySkillPoints;
            r.unlimitedLastBossWave = dto.unlimitedLastBossWave;
            r.unlimitedMaxTotalEnemies = dto.unlimitedMaxTotalEnemies;
            return r;
        }

        public static SaveMeta MakeMeta(SaveKind kind, string name, BuildData b, RunData r, WaveManager wm, int wave, List<string> attackNames)
        {
            var m = new SaveMeta
            {
                kind = kind,
                id = Guid.NewGuid().ToString("N"),
                name = SaveStore.NormalizeName(name),
                savedAtUtc = DateTime.UtcNow.ToString("o"),
                gameVersion = Application.version,
                wave = wave,
                waveManagerKind = wm is UnlimitedWaveManager ? WaveManagerKind.Unlimited : WaveManagerKind.Regular,
                difficultyName = wm != null && wm.difficulty != null ? wm.difficulty.name : "",
                modeName = wm != null && wm.mode != null ? wm.mode.name : "",
                ironman = IronmanSelector.Enabled,
                readOnly = kind == SaveKind.Build && IronmanSelector.Enabled,
                peakDps = b.peakDps,
                playtimeSeconds = b.playtimeSeconds,
                attackNames = attackNames ?? new List<string>()
            };

            void Ref(string id) { if (!string.IsNullOrEmpty(id) && !m.referencedIds.Contains(id)) m.referencedIds.Add(id); }

            foreach (var a in b.attacks) Ref(a.id);
            foreach (var u in b.upgradeIds) Ref(u);
            if (b.hasContract) Ref(b.contract.anomalyId);
            if (kind == SaveKind.Run && r != null)
            {
                Ref(r.sequenceId); Ref(r.difficultyId); Ref(r.modeId);
                foreach (var id in r.availableRareIds) Ref(id);
                foreach (var id in r.availableTreasureIds) Ref(id);
                foreach (var id in r.availableCorruptionSpecialIds) Ref(id);
            }

            return m;
        }

        public static List<string> AttackNames(GameObject player)
        {
            var names = new List<string>();
            if (player == null || !player.TryGetComponent<PlayerAttackHandler>(out var pah)) return names;
            foreach (AttackType t in Enum.GetValues(typeof(AttackType)))
            {
                AttackData a = pah.FindAttackOfType(t);
                if (a != null) names.Add(PlayerAttackHandler.NormalizeAttackName(a.name));
            }
            return names;
        }
    }
}
```

```csharp
using System.Collections.Generic;
using CrystalFlux.Core;
using CrystalFlux.EntitySystem;
using CrystalFlux.SkillTree;
using CrystalFlux.StatusEffectSystem;
using CrystalFlux.WaveSystem;
using UnityEngine;

namespace CrystalFlux.SaveSystem
{
    public static class BuildApplier
    {
        public static bool ApplyBuild(GameObject player, BuildData b, SaveAssetCatalog c)
        {
            if (player == null || b == null || c == null) return false;

            if (player.TryGetComponent<PlayerSkillTree>(out var tree))
                tree.RestoreUnlocked(b.skillTree.unlockedOrder, b.skillTree.skillPoints, b.skillTree.choseStarting);

            if (player.TryGetComponent<PlayerAttackHandler>(out var pah))
            {
                var attacks = new List<AttackData>();
                foreach (var slot in b.attacks)
                {
                    var a = c.Get<AttackData>(slot.id);
                    if (a == null) return false;
                    attacks.Add(a);
                }
                pah.SetAttacksExact(attacks);
            }

            if (player.TryGetComponent<PlayerUpgradeManager>(out var pum))
            {
                var ups = new List<PlayerUpgrade>();
                foreach (string id in b.upgradeIds)
                {
                    var u = c.Get<PlayerUpgrade>(id);
                    if (u == null) return false;
                    ups.Add(u);
                }
                pum.SetUpgradesExact(ups);
            }

            var permanent = new List<StatBuff>();
            if (player.TryGetComponent<StatusEffectManager>(out var sem)) sem.CollectAppliedStats(permanent);

            if (player.TryGetComponent<EntityStatManager>(out var esm))
            {
                esm.RestoreStatsJson(b.statsJson);
                foreach (StatBuff s in permanent)
                    if (!StatsMath.IsFlag(s.type)) esm.AddStat(s);
            }

            if (player.TryGetComponent<StatSynergyManager>(out var ssm))
            {
                var states = new List<(StatType, StatType, float, float)>();
                foreach (var s in b.synergies) states.Add((s.source, s.target, s.pct, s.applied));
                ssm.RestoreState(states);
            }

            if (tree != null) tree.RestoreUnlocked(null, b.skillTree.skillPoints, b.skillTree.choseStarting);

            DpsMeter.SetPeak(b.peakDps);
            RunSession.Playtime = b.playtimeSeconds;
            return true;
        }

        public static AnomalyInstance RecreateContract(BuildData b, SaveAssetCatalog c)
        {
            if (b == null || !b.hasContract || c == null) return null;
            AnomalyData amd = c.Get<AnomalyData>(b.contract.anomalyId);
            return amd != null ? amd.RecreateInstance(b.contract.creationState) : null;
        }

        public static bool ApplyRun(WaveManager wm, RunData r, SaveAssetCatalog c)
        {
            if (wm == null || r == null || c == null) return false;

            var dto = new RunStateDto
            {
                sequence = c.Get<WaveSequence>(r.sequenceId),
                waveIndex = r.waveIndex,
                rerolls = r.rerolls,
                additionalQuality = r.additionalQuality,
                synergyChanceBonus = r.synergyChanceBonus,
                pendingOccasionalRerolls = r.pendingOccasionalRerolls,
                pendingOccasionalSkillPoints = r.pendingOccasionalSkillPoints,
                pendingAnomalyRerolls = r.pendingAnomalyRerolls,
                pendingAnomalySkillPoints = r.pendingAnomalySkillPoints,
                unlimitedLastBossWave = r.unlimitedLastBossWave,
                unlimitedMaxTotalEnemies = r.unlimitedMaxTotalEnemies
            };
            foreach (var id in r.availableRareIds) { var a = c.Get<AttackAsset>(id); if (a != null) dto.availableRare.Add(a); }
            foreach (var id in r.availableTreasureIds) { var u = c.Get<UpgradeAsset>(id); if (u != null) dto.availableTreasure.Add(u); }
            foreach (var id in r.availableCorruptionSpecialIds) { var a = c.Get<AttackAsset>(id); if (a != null) dto.availableCorruptionSpecial.Add(a); }

            wm.RestoreRunState(dto);
            return true;
        }
    }
}
```

```csharp
namespace CrystalFlux.SaveSystem
{
    public class RunLoadTransaction
    {
        private readonly SaveFile file;
        private bool done;

        private RunLoadTransaction(SaveFile f) => file = f;

        public static RunLoadTransaction Begin(SaveFile f)
        {
            if (f?.meta != null && f.meta.kind == SaveKind.Run) SaveStore.Delete(SaveKind.Run, f.meta.id);
            return new RunLoadTransaction(f);
        }

        public void Commit() => done = true;

        public void Rollback()
        {
            if (done || file?.meta == null || file.meta.kind != SaveKind.Run) return;
            SaveStore.Write(file);
            done = true;
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using CrystalFlux.Core;
using CrystalFlux.SettingsSystem;
using CrystalFlux.WaveSystem;
using UnityEngine;

namespace CrystalFlux.SaveSystem
{
    public class RunSaveController : MonoBehaviour
    {
        public static RunSaveController Instance { get; private set; }
        public static event Action PendingBuildChanged;

        private GameObject player;
        private SaveAssetCatalog catalog;

        public static bool HasPendingBuild => RunSession.PendingLoad?.meta != null && RunSession.PendingLoad.meta.kind == SaveKind.Build;

        private void Awake()
        {
            Instance = this;
            catalog = SaveAssetCatalog.Instance;

            SaveFile pending = RunSession.PendingLoad;
            RunSession.ClearForNewScene();
            RunSession.PendingLoad = pending;

            WaveManager.WaveStarting += OnWaveStarting;
            WaveManager.PendingLoadStarter = StartPendingBuild;
        }

        private void OnDestroy()
        {
            WaveManager.WaveStarting -= OnWaveStarting;
            if (WaveManager.PendingLoadStarter == StartPendingBuild) WaveManager.PendingLoadStarter = null;
            if (ReferenceEquals(Instance, this)) Instance = null;
        }

        private void Start()
        {
            if (RunSession.PendingLoad?.meta?.kind == SaveKind.Run) ApplyPendingRun();
            else PendingBuildChanged?.Invoke();
        }

        private void Update() => RunSession.Tick(Time.deltaTime);

        private GameObject Player => player != null ? player : player = GameObject.FindGameObjectWithTag("Player");

        private WaveManager Wm => WaveManager.Active;

        private void OnWaveStarting(WaveManager wm)
        {
            RunSession.ClockRunning = true;
            if (catalog == null) return;
            RunSession.WaveStartBuild = BuildCapture.Capture(Player, catalog, wm.CurrentContract);
            RunSession.WaveStartRun = BuildCapture.CaptureRun(wm, catalog);
            RunSession.WaveStartNumber = wm.CurrentWaveNumber + 1;
        }

        private bool PlayerDead => DeathScreenUI.IsPlayerDead;

        public bool CanSaveProgress
        {
            get
            {
                WaveManager wm = Wm;
                return catalog != null && wm != null && RunSaveRules.CanSaveProgress(
                    wm.IsRunStarted, wm.IsWaveActive, wm.IsIdleBetweenWaves, RunSession.WaveStartRun != null, PlayerDead);
            }
        }

        public bool CanSaveBuild
        {
            get
            {
                WaveManager wm = Wm;
                return catalog != null && wm != null && RunSaveRules.CanSaveBuild(wm.IsRunStarted, wm.IsIdleBetweenWaves, PlayerDead);
            }
        }

        private int DisplayWave(WaveManager wm) => wm.IsIdleBetweenWaves ? wm.CurrentWaveNumber + 1 : RunSession.WaveStartNumber;

        public string DefaultProgressName
        {
            get
            {
                if (!string.IsNullOrEmpty(RunSession.CurrentRunName)) return RunSession.CurrentRunName;
                WaveManager wm = Wm;
                if (wm == null) return "Run";
                return RunSaveRules.DefaultRunName(wm.mode != null ? wm.mode.name : "", wm.difficulty != null ? wm.difficulty.name : "", DisplayWave(wm));
            }
        }

        public string DefaultBuildName
        {
            get
            {
                WaveManager wm = Wm;
                return RunSaveRules.DefaultBuildName(BuildCapture.AttackNames(Player), wm != null ? Mathf.Max(1, wm.CurrentWaveNumber) : 1);
            }
        }

        public bool SaveProgress(string name, bool overwriteExisting)
        {
            if (!CanSaveProgress) return false;
            WaveManager wm = Wm;

            BuildData b;
            RunData r;
            int wave;
            if (wm.IsIdleBetweenWaves)
            {
                b = BuildCapture.Capture(Player, catalog, wm.CurrentContract);
                r = BuildCapture.CaptureRun(wm, catalog);
                wave = wm.CurrentWaveNumber + 1;
            }
            else
            {
                b = RunSession.WaveStartBuild;
                r = RunSession.WaveStartRun;
                wave = RunSession.WaveStartNumber;
            }

            if (!Write(SaveKind.Run, name, overwriteExisting, b, r, wm, wave)) return false;

            RunSession.CurrentRunName = SaveStore.NormalizeName(name);
            GameSettings.Save();
            GameRestart.ToHomeScreen();
            return true;
        }

        public bool SaveBuild(string name, bool overwriteExisting)
        {
            if (!CanSaveBuild) return false;
            WaveManager wm = Wm;
            BuildData b = BuildCapture.Capture(Player, catalog, wm.CurrentContract);
            return Write(SaveKind.Build, name, overwriteExisting, b, null, wm, Mathf.Max(1, wm.CurrentWaveNumber));
        }

        private bool Write(SaveKind kind, string name, bool overwrite, BuildData b, RunData r, WaveManager wm, int wave)
        {
            string n = SaveStore.NormalizeName(name);
            if (n.Length == 0 || b == null) return false;

            SaveFile existing = SaveStore.FindByName(kind, n);
            if (existing != null && !overwrite) return false;

            var f = new SaveFile { build = b, run = r ?? new RunData() };
            f.meta = BuildCapture.MakeMeta(kind, n, b, r, wm, wave, BuildCapture.AttackNames(Player));
            if (existing != null) f.meta.id = existing.meta.id;

            return SaveStore.Write(f);
        }

        public void QueueLoad(SaveFile f)
        {
            if (f?.meta == null) return;
            RunSession.PendingLoad = f;

            WaveManager wm = Wm;
            if (wm != null && wm.IsRunStarted)
            {
                GameRestart.ToHomeScreen();
                return;
            }

            if (f.meta.kind == SaveKind.Run) ApplyPendingRun();
            else PendingBuildChanged?.Invoke();
        }

        public void ClearPendingBuild()
        {
            if (!HasPendingBuild) return;
            RunSession.PendingLoad = null;
            PendingBuildChanged?.Invoke();
        }

        private WaveManager FindManager(WaveManagerKind kind)
        {
            foreach (var wm in FindObjectsByType<WaveManager>(FindObjectsInactive.Include, FindObjectsSortMode.None))
            {
                bool unlimited = wm is UnlimitedWaveManager;
                if (kind == WaveManagerKind.Unlimited ? unlimited : wm.GetType() == typeof(WaveManager)) return wm;
            }
            return null;
        }

        private void ApplyPendingRun()
        {
            SaveFile f = RunSession.PendingLoad;
            RunSession.PendingLoad = null;
            if (f == null || catalog == null) return;

            RunLoadTransaction tx = RunLoadTransaction.Begin(f);
            try
            {
                WaveManager wm = FindManager(f.run.waveManagerKind);
                DifficultyData d = catalog.Get<DifficultyData>(f.run.difficultyId);
                ModeData m = catalog.Get<ModeData>(f.run.modeId);
                if (wm == null || d == null || m == null) throw new InvalidOperationException("Run save references missing data");

                IronmanSelector.SetEnabled(f.run.ironman);
                DifficultySelector.Current?.Select(d);
                ModeSelector.Current?.Select(m);
                DifficultySelector.Current?.LockIn(wm);
                ModeSelector.Current?.LockIn(wm);
                IronmanSelector.Current?.LockIn();

                if (!BuildApplier.ApplyBuild(Player, f.build, catalog)) throw new InvalidOperationException("Build restore failed");
                wm.RestoreContract(BuildApplier.RecreateContract(f.build, catalog));
                if (!BuildApplier.ApplyRun(wm, f.run, catalog)) throw new InvalidOperationException("Run restore failed");

                RunSession.CurrentRunName = f.meta.name;
                tx.Commit();
                wm.StartLoadedRun();
            }
            catch (Exception e)
            {
                Debug.LogWarning($"[RunSaveController] Load failed: {e.Message}");
                tx.Rollback();
                GameRestart.ToHomeScreen();
            }
        }

        private bool StartPendingBuild(WaveManager wm)
        {
            if (!HasPendingBuild || catalog == null) return false;

            SaveFile f = RunSession.PendingLoad;
            RunSession.PendingLoad = null;

            if (!BuildApplier.ApplyBuild(Player, f.build, catalog))
            {
                Debug.LogWarning("[RunSaveController] Build restore failed");
                PendingBuildChanged?.Invoke();
                return false;
            }

            wm.RestoreContract(BuildApplier.RecreateContract(f.build, catalog));
            if (Player != null) wm.RemoveOwnedFromPools(Player.GetComponent<IAttackHandler>(), Player.GetComponent<IUpgradeHolder>());
            RunSession.Playtime = 0f;
            DpsMeter.SetPeak(0f);
            PendingBuildChanged?.Invoke();
            wm.StartLoadedRun();
            return true;
        }
    }
}
```

```csharp
                return;

            SaveFile existing = SaveStore.FindByName(kind, name);
            if (existing != null && existing.meta.id != ignoreId)
```

```csharp
using System;
using System.Globalization;
using System.Text;

namespace CrystalFlux.SaveSystem
{
    public static class SaveInfoFormatter
    {
        public static string FormatPlaytime(float seconds)
        {
            int total = Math.Max(0, (int)seconds);
            int h = total / 3600, m = total % 3600 / 60, s = total % 60;
            return h > 0 ? $"{h}h {m:00}m" : $"{m}m {s:00}s";
        }

        public static string FormatDate(string iso)
            => DateTime.TryParse(iso, CultureInfo.InvariantCulture, DateTimeStyles.RoundtripKind, out DateTime d)
                ? d.ToLocalTime().ToString("yyyy-MM-dd HH:mm", CultureInfo.InvariantCulture)
                : iso ?? "";

        public static string Lines(SaveMeta m, string incompatibleReason)
        {
            var sb = new StringBuilder();
            sb.Append("Wave ").Append(m.wave).Append('\n');
            sb.Append(m.modeName).Append(" / ").Append(m.difficultyName);
            if (m.ironman) sb.Append(" / Ironman");
            sb.Append('\n');
            sb.Append("Highest DPS: ").Append(m.peakDps.ToString("N0", CultureInfo.InvariantCulture)).Append('\n');
            if (m.attackNames != null && m.attackNames.Count > 0) sb.Append("Attacks: ").Append(string.Join(", ", m.attackNames)).Append('\n');
            sb.Append("Playtime: ").Append(FormatPlaytime(m.playtimeSeconds)).Append('\n');
            sb.Append("Saved: ").Append(FormatDate(m.savedAtUtc));
            if (m.readOnly) sb.Append("\n<color=#FFC857>Read only (Ironman)</color>");
            if (!string.IsNullOrEmpty(incompatibleReason)) sb.Append("\n<color=#FF6B6B>Incompatible: ").Append(incompatibleReason).Append("</color>");
            return sb.ToString();
        }
    }
}
```
